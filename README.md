# Calculadora Web con Servlets en Java

Este proyecto es una calculadora web sencilla desarrollada en Java
utilizando Servlets y un formulario HTML.

## Funcionamiento
- El usuario ingresa dos números desde un formulario HTML.
- Selecciona la operación matemática (suma, resta, multiplicación o división).
- Los datos se envían al Servlet mediante el método POST.
- El Servlet procesa los datos y muestra el resultado en el navegador.

## Tecnologías utilizadas
- Java
- Servlets
- HTML
- Apache Tomcat
- NetBeans
